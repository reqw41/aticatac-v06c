# Журнал

## 2026-10-25 — разведка, сборка CPC, прототип вывода

**Решение.** Порт по CPC-версии (github.com/shaymanjohn/aticatac-cpc, Z80, Mode 0 128×192, 16 цветов),
движок вывода «как Old Tower»: спрайты XOR, графика в квазидиске через стековый режим. Цели — цветная версия
для квазидиска и урезанная для ванильного Вектора 64К. У CPC-исходников нет лицензии: только приватно,
перед публикацией спросить автора.

**Окружение (не в git, см. .gitignore).**
- `ref/cpc` — клон CPC-репозитория; `ref/zx/atic-atac` — skool/ctl mrcook (запасной источник).
- `tools/src/rasm` → `tools/rasm` (rasm 3.3.2: `make -f makefile.MacOS CC=/usr/bin/clang ARCH="-arch arm64"`).
- `tools/sjasmplus` — сборка прототипа (`--i8080`).
- `stand/cpc`: `aticatac.dsk`, `roms` (ссылка на ~/projects/knightlore-research/cpc/roms), `bg8000.bin` —
  экран комнаты 0 из MAME (`dumproom.lua`, точка 0x82B CALCULATE_COLLISION_GRID), нужен tools/mkproto.py.
- Ядро эмулятора Вектора — ~/projects/vector06js (переменная V06JS).

**Сделано.**
1. `tools/build_cpc.sh` — CPC собирается байт в байт с образом дискеты (`tools/dskextract.py` достаёт файлы
   AMSDOS для сверки); символы — build/cpcsrc/rasmoutput.sym.
2. Темп оригинала в MAME (`stand/cpc/*.lua`, `tools/cpcprof.py`): 50 к/с; кадр 20 мс = простой 7.8,
   спрайты ≈5.6, музыка ≈2.7, логика ≈4 мс. → docs/FEASIBILITY.md.
3. Прототип `proto/proto.asm` + `tools/mkproto.py`: фон комнаты 0, 6 объектов (рыцарь, топор, призрак,
   летучая мышь, ведьма, тыква) отражаются от стен; XOR из квазидиска развёрнутым циклом POP.
   Проверка стирания `-DERASECHK` — 0 отличий от фона.
4. Стенды Вектора headless (`stand/vec`): `run.js` — такты на тик, `frames.js` + `tear.py` — кадры «как видит
   луч» и доля артефактов, `flicker.sh` — всё сразу, `gif.py`/`shot.py` — картинки.
5. Привязка к лучу `-DBEAM`: положение луча по ВИ53 (счётчик 0, режим 2, делитель 29952 = кадр),
   объект выводится, только когда луч не зайдёт в его строки. Занимает счётчик 0 — конфликт с музыкой на ВИ53.
6. 8 цветов (`COLORS=8`): перебор восьмёрки перьев по частоте, плоскость 0xE000 свободна (+8К ОЗУ).
   Потери: жёлтое → оранжевое, зелёное → голубое.
7. 1:1 (`PIX=1`): пиксель CPC = точка, картинка 128×192 по центру, 8 фаз сдвига; вид вдвое уже.

| вариант | без луча, тиков/с | с лучом | чистых кадров | худший |
|---|---|---|---|---|
| 16 точек, 16 цветов | 26.8 | 20.6 | 137/145 | — |
| 16 точек, 8 цветов | 33.6 | 24.9 | 120/145 | 6.4 % |
| 1:1, 8 цветов | 43.4 | 34.6 (WIN_U=60) | 112/140 | 3.8 % |

Тик = все 6 объектов стёрты, сдвинуты и нарисованы. Подробности — docs/PROTO.md.

**Почему CPC быстрее:** Z80 4 МГц с шагом 1 мкс против 8080 3 МГц, где простая команда 8 тактов (2.7 мкс);
байт Mode 0 несёт 2 пикселя со всем цветом, у Вектора цвет разнесён по плоскостям; у CPC аппаратный двойной
буфер, на Векторе ожидание луча съедает 20–30 %.

**Состояние build/proto:** см. последнюю запись журнала.

**Открыто.**
- Выбор вида: 16 точек (как CPC, 25–33 тика/с) или 1:1 (35–43, узкая картинка); владелец смотрит.
- WIN_U=60 не перемерен на варианте 16 точек.
- Резервы: стирание записью нуля на чёрном полу, 2 фазы сдвига вместо 4 (память), убрать copy_obj.
- Фаза таймера (OFS_U) на MiSTer; ванильная 64К-версия; лицензия CPC.
