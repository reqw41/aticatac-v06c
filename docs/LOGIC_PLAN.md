# Логика и ход игры: план (с 25.10.2026)

Решение владельца: логика CPC переносится через **JS-модель** (сверка с CPC по шагам), потом —
**i8080 с оптимизацией** (сверка с JS-моделью). Отрисовка — своя (docs/PROTO.md: комнаты, спрайты без XOR).

## Этапы
0. **Эталон CPC.** Своя модель CPC 6128 на JS (`tools/cpc6128.js`: Z80 из Indy с исправленным INI/IND,
   банки C0/C4..C7, PPI/PSG-клавиатура, 6 прерываний на кадр, такты по 4). Игра грузится из сборки
   (build/cpcnew) без дискеты. `tools/cpc_trace.js <сценарий>` пишет шаги в build/golden/*.json.gz.
1. **JS-модель** (src/model/): функции по подпрограммам CPC, память — в раскладке CPC (страницы 0, 1, 5),
   вывод не моделируется. Сверка по шагам с эталоном (tools/model_run.js).
2. **i8080** по модулям: тот же порядок, сверка с JS-моделью покомандно/по шагам; оптимизация под 8080
   (без IX/IY, данные в удобной раскладке — когда сверка зелёная).
3. **Сборка игры на Векторе:** логика + комнаты (proto/room.asm) + спрайты без XOR (proto.asm -DOVR) +
   клавиатура/джойстик + звук.

## Шаг и состояние
- Шаг = вызов задачи состояния из главного цикла (`current_game_state`: game_tasks / falling_tasks /
  end_tasks / menu_tasks). На CPC 1 кадр на шаг (50 Гц).
- Состояние = страница 0 (код и переменные 0x0000–0x3FFF; самомодифицируемые места — тоже), банк
  предметов (стр. 1), банк комнат (стр. 5). Экраны, графика (стр. 4, 7) и звук (стр. 6) — нет.
- **Адреса прерывания** — всё, что пишет обработчик (клавиатура, часы, heartbeat, звук, экраны);
  их нет в сравнении. Их чтения игрой посреди шага (клавиатура опрашивается ~3.3 мс после начала шага)
  записаны в эталоне по порядку (`rd`) — модель берёт значения из этой очереди.
- Случайность: `ld a,r` — значения в эталоне (`r`); RANDOM_IN_A дальше детерминирован.
- Звук: номера эффектов на входе play_sfx (`sfx`) — сверяются.

## Сценарии (research/scenarios)
- s0_random — случайные клавиши (за 3000 шагов из комнаты 0 не выходит).
- Нужны: политика «к двери» (обход комнат), смерти, ключи и двери, люки (падение), еда, боссы
  (Дракула, мумия, Франкенштейн, горбун, дьявол), курица, победа. Покрытие — по подпрограммам.
